# نظام لإدارة المبيعات

برنامج لإدارة المبيعات مبني بلغة C# باستخدام Windows Forms.
أبنيه بالتزامن مع تعلمي لدورة خالد السعداني.

## المميزات
- إدارة المنتجات
- إدارة العملاء
- إدارة المستخدمين
- تسجيل فواتير البيع

## التقنيات المستخدمة
- C#
- Visual Studio 2022
- قاعدة بيانات (SqlServer)

## كيفية التشغيل
1. حمّل المشروع.
2. افتح ملف `.sln` في Visual Studio.
3. اضغط F5 للتشغيل.
