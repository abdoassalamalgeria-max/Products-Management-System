# نظام لإدارة المبيعات

برنامج لإدارة المبيعات مبني بلغة C# باستخدام Windows Forms وقواعد بيانات SqlServer في بيئة .NET في Visual Studio 2022.

## المميزات
- إدارة المنتجات Products
- إدارة الأصناف Categories
- إدارة العملاء Clients
- إدارة المستخدمين Users
- تسجيل فواتير البيع Orders_Details

## التقنيات المستخدمة
- C# and WindowsForms.
- Visual Studio 2022.
- Sql Server 2019 for Databases.
- SSMS.
## كيفية التشغيل
1. حمّل المشروع.
2. افتح ملف `.sln` في Visual Studio.
3. في الكلاص DataAccessLayer.cs قم بتغيير اسم قاعدة البيانات DataBase واسم السيرفر Server الى الخاصين بك.
4. داخل قاعدة البيانات الخاصة بك قم باضافة اسم مستخدم وكلمة مرور في الحقلين ID و PWD.
5. في الفجوال ستوديو اضغط F5 للتشغيل.
